**Automation Data Framework**

**Description**

This repository provides reusable data integration handlers designed to decouple test scripts from environment configurations, test datasets, and database states. It consists of three primary modules:

**ExcelIntg:** Handles Excel (.xlsx) sheet interactions using Apache POI, integrated with Java Faker for dynamic test data generation.

**YamlIntg:** Parses static and multi-environment configuration files (.yaml / .yml) using SnakeYAML for flexible environment switching (QA, Dev, Staging).

**DBIntg:** Executes relational database operations (MySQL) via JDBC Statement and PreparedStatement to pre-seed test state and run post-execution database assertions.

**Operations**
**ExcelIntg (Apache POI + Java Faker)**

**Creation:** Instantiates an in-memory XSSFWorkbook object and creates sheets (createSheet), rows (createRow), and cells (createCell).

**Load:** Reads local .xlsx files using FileInputStream and initializes XSSFWorkbook(fis) to parse the sheet structure into memory.

**Insert (Faker Integration):** Populates cells dynamically with synthetic values generated by Java Faker (faker.name().fullName(), faker.internet().emailAddress()).

**Update:** Accesses specific row/column coordinates using sheet.getRow(index).getCell(index) and updates values using .setCellValue(newValue). The updated workbook is saved via FileOutputStream.

**Delete:** Clears content using sheet.removeRow(row) and adjusts layout with sheet.shiftRows(startRow, endRow, -1) to eliminate blank gaps.

**YamlIntg (SnakeYAML)**

**Creation:** Defines structured configuration files using key-value pairs, nested maps, and array lists (.yaml or .yml).

**Load:** Uses FileInputStream combined with SnakeYAML's Yaml.load() to parse YAML content into strongly typed Java Map<String, Object> objects.

**Read / Query:** Retrieves nested configuration values programmatically (e.g., extracting environment-specific URLs or credentials like config.get("qa").get("db_url")).

**Update:** Modifies loaded in-memory Java maps and writes the updated mapping back to disk using SnakeYAML's Yaml.dump(map, writer).

**Delete:** Removes keys or sections directly from Java Map objects at runtime prior to execution or environment teardown.

**DBIntg (JDBC + MySQL Connector/J)**

**Creation (DDL):** Executes CREATE TABLE IF NOT EXISTS schema definitions using Statement.execute(sql).

**Load / Read (DQL):** Executes SELECT statements via PreparedStatement.executeQuery() and iterates through returned records using ResultSet.next(). Safe data parsing is handled via resultSet.getInt(), getString(), etc.

**Insert (DML):** Executes parameterized INSERT INTO table (cols) VALUES (?, ?, ?) queries using PreparedStatement.executeUpdate() with safe parameter mapping (setString, setInt).

**Update (DML):** Modifies existing database entries with UPDATE table SET col = ? WHERE condition = ? using PreparedStatement.executeUpdate().

**Delete (DML):** Removes target records with DELETE FROM table WHERE condition = ? or resets tables using DROP TABLE IF EXISTS / TRUNCATE TABLE statements.
